# Glossary

| Term | Meaning |
|---|---|
| **Maintenance window** | A recurring period when OK040 is powered on to run planned backups, backup integrity checks and disk-health tests. The schedule also accounts for the user's weekday availability and planned rest periods. |
| **Project backup folder** | `backups/<project>/` inside the `joost` home share on the NAS: where one Mac project's dated backup copies are stored. Each project uses its own subfolder. |
